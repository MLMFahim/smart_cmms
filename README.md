# Smart Inventory & Maintenance Planner (Smart CMMS)

A Flask-based web application designed to track facility assets, manage spare parts inventory, and handle maintenance work order dispatches.

## Features
* **Asset Registry:** Full details modal displaying operational status, facility location, voltage, and maintenance intervals.
* **Spare Parts Inventory:** Low-stock tracking, bin storage mapping, and supplier details.
* **Work Order Dispatch:** Interactive assignment of maintenance tasks to target assets and technicians.
